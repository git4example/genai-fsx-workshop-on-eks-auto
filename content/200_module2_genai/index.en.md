## Module overview

In this module, you will configure and deploy a Generative AI chatbot application on Kubernetes by deploying a vLLM and a WebUI Pod on an Amazon EKS cluster, store and access the Mistral-7B model using Amazon FSx for Lustre and Amazon S3, and leverage Accelerate Compute for your Generative AI workload using AWS Inferentia Accelerator.
